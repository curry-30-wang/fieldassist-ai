# 沥青拌合站软件图标设计

## 目标

将 Windows 桌面上的默认控制面板样式替换为能代表沥青拌合站经营管理系统的自定义图标。

## 设计

- 采用深蓝色圆角底，保持与软件主界面一致。
- 中心使用橙黄色沥青料流和简化的拌合站塔楼轮廓，缩小到桌面图标尺寸后仍能辨认。
- 不放文字，避免小尺寸下文字模糊。
- 保留透明外边缘，并输出 Windows `.ico` 多尺寸图标。
- 仅修改应用程序图标配置，不改变业务功能、数据文件或安装流程。

## 交付与验证

- 生成源图并保存到项目资源目录。
- 生成包含 16、24、32、48、64、128、256 像素尺寸的 `.ico` 文件。
- 在 WPF 项目中设置应用图标并确认 Release 构建成功。
- 本轮不生成安装包；最终安装包由后续所有功能修改完成后统一生成。
