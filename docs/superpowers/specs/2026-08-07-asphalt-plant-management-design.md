# 沥青拌合站经营管理系统设计说明

## 1. 项目目标

开发一套供单台 Windows 10/11 电脑离线使用的沥青拌合站经营管理软件。软件用于填写、计算、封存、归类、查询、打印和导出经营生产表格，并允许后续持续增加新模板。

软件暂定名为“沥青拌合站经营管理系统”。软件名称、公司名称、项目名称及其他常用名称均可在设置或基础资料中修改。

## 2. 技术方案

- 使用 C#/.NET 开发 Windows 原生桌面程序。
- 使用 SQLite 保存本地数据，无需安装或维护数据库服务。
- 软件完全离线运行，不上传经营数据。
- 提供 Windows 安装包和桌面快捷方式。
- 不依赖 Microsoft Excel 也能生成 Excel 和 PDF 文件。

## 3. 功能模块

### 3.1 首页

显示今日产量、沥青消耗、库存、应收欠款、最近填写记录，以及待回款、库存偏低和即将保养等提醒入口。

### 3.2 新建表格

用户先选择模板，再填写记录。表格支持自动计算、增删行、保存草稿、复制上一张表、完成、封存、打印和导出。

### 3.3 封存档案

支持按年份、月份、模板类型、客户、工程、材料规格、档案编号、状态和关键词组合查询。

### 3.4 基础资料

维护软件名称、公司、客户、工程项目、材料规格、配合比、车辆、司机、供应商和常用人员等资料。基础资料变更只影响新表，已封存历史表保留当时快照。

### 3.5 统计报表

提供产量、原材料库存、采购、销售、回款、欠款、运输和设备费用等汇总统计。

### 3.6 打印与导出

提供打印预览、A4 横向或纵向打印、Excel 导出和 PDF 导出。

### 3.7 系统设置与备份恢复

支持修改系统显示名称、默认表头、打印信息、数据和备份位置；支持自动备份、手动备份及备份恢复。

## 4. 首批内置模板

1. 沥青购耗存明细表：日期、上期结余、本日购进、规格型号、沥青配合比、生产量、本日消耗、本日结余。
2. 客户/工程对账单：日期、客户、工程部位、规格、车数、数量、单价、材料金额、油费、运费、供货总额、回款、累计欠款和对账结果。
3. 沥青混合料生产日报：班次、配合比、各规格产量、生产时间、操作员、停机原因和备注。
4. 原材料入库单：材料、供应商、车号、毛重、皮重、净重、单价和验收情况。
5. 原材料库存盘点表：账面库存、实际库存、盈亏数量、盈亏金额和处理意见。
6. 成品出库/发货记录：客户、工程、车辆、司机、规格、过磅重量、发货时间和签收情况。
7. 销售与回款明细：合同金额、累计供货、已回款、未回款、账龄和约定付款日期。
8. 设备运行与维修记录：设备、运行时长、故障现象、维修内容、配件费用和下次保养日期。
9. 燃油购耗存明细：柴油购入、设备或车辆领用、单价、金额和库存。
10. 质量检验记录：混合料类型、取样批次、检测项目、标准值、实测值、结论和检验人员。
11. 车辆运输结算表：车辆、司机、趟数、吨数、运距、运价和费用。
12. 安全巡检记录：检查区域、隐患、风险等级、负责人、整改期限和复查结果。

具体字段和计算规则在实施时以本设计和桌面“图片”目录中的六张样例照片共同为依据。

## 5. 模板持续扩展设计

模板采用独立、可扩展的定义方式。每个模板包含以下内容：

- 模板唯一标识、名称、分类和版本；
- 表头信息和明细字段；
- 字段类型、必填规则、默认值和下拉选项；
- 自动计算及合计规则；
- 查询索引字段；
- 打印版式和 Excel/PDF 导出规则。

新增模板时，不修改已有模板的历史定义，也不迁移或破坏既有档案。已封存表格保存模板版本和完整数据快照，保证未来模板升级后仍能按原版查看和打印。

首版采用由开发方加入并验证新模板的稳健方式，同时预留模板管理入口。后续可升级为可视化模板设计器，让用户自行配置字段和打印布局；该设计器不属于首版验收范围。

## 6. 数据状态、封存与版本

表格状态流转为：草稿、已完成、已封存、已解封；“重新封存”不再是用户每次修改后的必需操作。

- 封存时生成唯一档案编号，例如 `DZ-202608-0001` 或 `GHC-202608-0001`。
- 单机单人模式下，每次应用启动后，用户首次编辑已封存档案时输入一次解封密码；验证成功只在当前应用会话内生效。
- 当前会话解封后，已封存档案可随时编辑；不要求逐份解封，也不要求修改后反复重新封存。
- 每次保存已封存档案的修改均在事务中自动生成新版本，旧版本永久保留。
- 每个版本记录修改时间和修改说明。
- 用户可查看、对比和恢复历史版本。
- 删除进入回收站，可恢复，避免直接丢失数据。
- 归档元数据包括模板、日期范围、客户、工程、材料规格、经办人、金额、备注和封存时间。

## 7. 查询与归类

软件数据库是档案的权威来源。用户可组合筛选，例如“2026 年 8 月、某客户、AC-13、尚有欠款”。导出的 Excel 和 PDF 文件按年份、月份及模板类型自动建立目录并采用档案编号命名。

## 8. 打印与导出规则

- 每种模板配置专用 A4 版式；宽表默认横向，记录单可纵向。
- 支持打印预览、页边距、分页表头、页码、签字栏和盖章位置。
- 可配置公司名称、联系方式、制表人、审核人和备注是否显示。
- 打印件显示档案编号、版本号和打印时间。
- PDF 与打印版式保持一致。
- Excel 文件保留标题、表头、边框、合计公式和数字格式。

## 9. 数据安全和异常处理

- 编辑过程中自动保存草稿，程序异常退出后可继续填写。
- 每天首次正常退出时创建自动备份，并轮换保留最近若干份。
- 支持备份到 U 盘或其他磁盘。
- 恢复前自动保存当前数据，恢复失败时保持当前数据库不变。
- 对日期、吨数、单价、金额等输入进行格式和合理性校验。
- 对负库存、异常欠款、库存偏低等情况给出提示，但不擅自修改用户数据。
- 打印或导出失败不改变原表和封存状态，并显示可理解的错误提示。

## 10. 组件边界

- 界面层：导航、表格编辑、搜索、预览和设置。
- 模板引擎：加载模板、字段校验、公式计算和模板版本管理。
- 档案服务：状态流转、编号、快照、版本和回收站。
- 查询统计服务：组合查询、首页指标和经营汇总。
- 输出服务：打印预览、Windows 打印、Excel 和 PDF 生成。
- 数据层：SQLite 读写、事务和数据库升级。
- 备份服务：自动备份、手动备份、校验和恢复。

各组件通过明确接口协作，新增模板原则上只增加模板定义和对应版式，不改动档案、查询、备份等核心机制。

## 11. 测试与验收

- 可在普通 Windows 10/11 电脑上安装、启动和离线运行。
- 12 种首批模板均可新建、保存、计算、完成、封存、解封和查询。
- 关键计算使用典型值、零值、小数和异常值测试。
- 可按多个条件快速找到历史档案。
- 旧模板数据在模板升级或新增模板后仍能正确打开和打印。
- A4 打印无内容截断，分页表头、合计、签字栏和页码正确。
- Excel 和 PDF 导出内容、数值和版式正确。
- 关闭并重新打开软件后，数据和历史版本完整保留。
- 自动备份、手动备份和恢复均经过实际验证。
- 提供安装包、简明使用说明和演示数据。

## 12. 首版范围边界

首版仅面向单机单用户，不包含联网同步、多人权限、手机端、云存储和用户自行设计复杂打印模板。系统结构必须为后续新增业务模板保留扩展能力。
