# Excel 工作流效率改进设计

## 目标

在现有 Excel-first 流程上增加实用的效率功能：导入前预览、草稿管理、封存档案的 Excel 修改、规格记忆、常用模板收藏和公司名称自动显示。明确不增加自动备份提醒。

## 功能设计

### 1. 导入前预览

“导入 Excel”只读取并校验文件，不立即写入数据库。页面显示模板、期间、明细行数、规格摘要和校验结果；只有点击“确认并封存”后才创建记录和复制 Excel 文件。预览失败时不产生草稿、档案或版本。

### 2. 草稿与最近文件

软件扫描“我的文档\\沥青拌合站管理系统\\Excel草稿”中的 `.xlsx` 文件，按修改时间显示最近文件。用户可以打开文件或打开所在文件夹；不新增数据库表，也不自动删除草稿。

### 3. 封存档案用 Excel 修改

档案页面增加“导出可编辑 Excel”按钮，生成带有导入元数据的工作簿。用户修改并保存后，在档案页面选择该文件导入；软件要求先解锁当前会话，校验模板和数据后，将修改保存为新版本。

### 4. 版本保留规则

每个档案最多保留最近两版：首次封存是 v1；产生 v2 后保留 v1、v2；产生 v3 后自动删除 v1，只保留 v2、v3。恢复历史版本也会生成新版本，并在同一事务中执行清理。删除的旧版本不在档案页面显示，数据库备份仍按备份时状态保存。

### 5. 规格记忆

从已保存的基础资料和历史档案中收集规格文字，在 Excel 生成前显示为可选建议；建议不是强制选项，仍允许直接输入全新的规格。

### 6. 常用模板收藏

在新建表格页面为模板提供收藏开关。收藏状态保存到本机设置，重新启动后仍保留；收藏模板排在未收藏模板前面，不改变模板 ID、版本或 JSON 文件。

### 7. 公司名称自动显示

启动和进入设置页面时读取已保存的公司名称，显示在顶部栏；生成 Excel 时继续使用同一名称。未设置时显示“未设置公司名称”，不阻塞其他功能。

## 数据与错误处理

- 预览和档案编辑共用现有 Excel 导入校验，不重复实现公式计算。
- 任何导入校验失败都只显示错误，不写入 records 或 record_versions。
- 档案编辑必须先通过当前会话解锁；解锁失败不打开编辑保存流程。
- 版本新增、旧版本清理和 records 更新必须在同一 SQLite 事务中完成。
- 不增加网络、登录、云端同步、自动备份提醒或复杂图表。

## 验证范围

- Core：预览模型和版本保留边界测试。
- Infrastructure：可编辑档案 Excel 元数据往返、坏文件阻止写入、版本清理只保留两版。
- App：预览确认按钮、草稿列表、公司名称加载、模板收藏排序和档案编辑命令绑定。
- Release 全量测试通过后再考虑生成安装包；本次功能开发不生成安装包。
