# 沥青拌合站经营管理系统使用手册

## 1. 安装和启动

1. 双击安装包，按提示完成安装。
2. 安装后，双击桌面上的“沥青拌合站经营管理系统”快捷方式。
3. 电脑需要安装 Excel，或能编辑 `.xlsx` 文件的兼容软件。

## 2. 第一次使用

打开“设置”：

- 填写公司名称。
- 设置封存档案的解锁密码。

打开“基础资料”，按需要填写客户、供应商、车辆、司机和常用规格。没有的规格，也可以直接在 Excel 里输入。

## 3. 新建一张表格

1. 点击“新建表格”。
2. 选择表格模板和日期。
3. 点击“在 Excel 中填写”。
4. 在 Excel 里填写、调整列宽、行高、公式和打印格式。
5. 保存 Excel 文件，回到软件点击“导入 Excel 并预览”。
6. 检查预览内容，确认无误后点击“确认并封存”。

封存后，软件会生成档案编号，并保存一份档案副本。规格可以直接输入新的文字。

注意：不要删除 Excel 中隐藏的 `__FormMeta` 工作表，否则软件可能无法识别这张表。

## 4. 查询、打印和修改档案

打开“档案”：

- 可按日期、客户、工程、规格或关键词查询。
- 可导出 Excel、可编辑 Excel 或 PDF。
- 打印前建议先点击“打印预览”。

修改已封存档案：

1. 选中档案，点击“导出可编辑 Excel”。
2. 输入一次解锁密码。
3. 修改并保存 Excel。
4. 回到软件，点击“导入修改后的 Excel”。

每个档案只保留最近两版，第三版产生后，最早的一版会自动删除。

## 5. 客户欠款

“客户欠款”是单独的简单清单，不需要每次生产都填写。

填写客户、应收金额、已收金额、收款日期和备注后，软件会自动计算剩余欠款。选中记录后可以修改、删除或导出客户对账 Excel。

## 6. 备份和恢复

1. 打开“备份”。
2. 选择备份目录，点击“手动创建备份”。
3. 建议定期把备份复制到 U 盘或其他硬盘。

恢复数据时：

1. 填写备份文件夹路径。
2. 点击“验证备份”。
3. 验证通过后，勾选确认项，再点击“从备份恢复”。
4. 恢复完成后，重新打开软件。

恢复会覆盖当前数据，操作前请先做一次当前数据备份。

## 7. 常见问题

- **Excel 打不开**：安装 Excel 或其他能编辑 `.xlsx` 的软件。
- **导入失败**：确认文件已保存为 `.xlsx`，并且没有删除隐藏的 `__FormMeta` 工作表。
- **打印失败**：检查打印机是否已连接，再使用“打印预览”。
- **忘记解锁密码**：软件不能直接绕过密码，请使用以前的备份或联系维护人员。
- **换电脑**：先备份数据，在新电脑安装软件后，再从“备份”页面恢复。

数据保存在本机。建议养成定期备份的习惯。
