# 深蓝工业风前端设计

## 目标

让单机版沥青拌合站管理系统更容易扫读和操作：用户进入页面后能迅速分辨当前模块、重点数据、下一步操作和异常提醒。只改变 WPF 前端视觉与布局，不改变 Excel、档案、搜索、备份和封存业务。

## 设计方向

采用深蓝工业风：左侧导航使用深海军蓝，当前模块使用亮蓝色高亮；内容区使用浅灰背景和白色卡片；主操作使用蓝色，成功/库存使用青绿色，警告使用橙色，错误使用红色。整体保持 Microsoft YaHei 和现有 Windows 控件兼容，不引入第三方 UI 框架。

## 页面结构

- 全局：左侧固定导航、顶部页面标题栏、右侧内容区、底部状态条。
- 导航：分为“工作台”“表格与档案”“基础资料”“系统管理”四个视觉分组，保留整行点击和现有页面名称。
- 首页：标题与日期、四个指标卡片、快捷操作卡片、提醒横幅、最近档案表格。
- 新建表格：模板/日期选择卡片、Excel 三步操作说明卡片、两个主按钮；隐藏旧的内置字段网格。
- 档案：查询条件卡片、结果表格卡片、版本和打印操作卡片。
- 基础资料/备份/设置：统一白色卡片、清晰标题、字段说明、主次按钮和状态提示。

## 交互与可读性

- 导航行在普通、悬停、选中状态有明显背景变化；点击整行均可切换页面。
- 卡片使用统一圆角、内边距和阴影，避免信息黏在一起。
- 页面主按钮只保留一到两个视觉重点，辅助操作使用次级按钮。
- 重要数字使用较大字号；提醒和错误不只依赖颜色，同时保留文字。
- 窗口最小尺寸保持现有值；内容区允许滚动，不改变已有命令和绑定。

## 范围控制

- 不修改数据库、模板 JSON、Excel 工作流或档案服务。
- 不增加登录、云端、多用户、动画库或复杂图表。
- 不生成安装包；完成后仅运行 WPF 编译和现有测试。
