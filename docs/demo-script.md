# FieldAssist 3–5 分钟演示脚本

## 0:00–0:30 启动和登录

1. 执行 README 中的 Mock 启动命令，打开 `http://127.0.0.1:8000/`。
2. 使用 `employee@fieldassist.local` 和本地演示密码登录。
3. 指出这是同源静态页面：没有 Dify/Langfuse 密钥也能完成演示。

## 0:30–2:00 员工问答闭环

1. 新建一个“政策咨询”会话。
2. 输入“年假需要提前多久申请？”，展示 Mock 返回的回答和“员工请假政策”来源。
3. 在反馈说明中写一句话，点击“有帮助”；再展示工单入口。
4. 点击“转为工单”，填写标题、描述和中优先级，提交后打开“我的工单”，说明员工只能看到自己的工单。

## 2:00–3:00 管理员运营视图

1. 退出并使用 `admin@fieldassist.local` 登录。
2. 打开“运营概览”，展示累计问题、平均响应、正向反馈率、开放工单和 Mock 提供方调用次数。
3. 展示“服务连接状态”：应用、Mock AI、Mock 可观测性和 SQLite 都是正常状态。
4. 打开“知识文档”，说明页面只展示元数据，不返回文档全文。

## 3:00–4:30 工单和评测

1. 打开“工单管理”，把工单从待处理推进到处理中，展示管理员能看全局记录。
2. 打开“质量评测”，点击“运行评测”。
3. 展示逐题结果、通过数和总体得分，说明每题必须命中全部预期关键词，单题失败也会继续保存其他题结果。

## 4:30–5:00 交付价值

说明真实模式只需在后端环境变量配置 Dify Chat API 和 Langfuse；Dify 负责 AI 对话，Langfuse 负责追踪，FieldAssist 负责权限、业务闭环和可交付的管理视图。n8n 是后续工单自动化扩展，不是当前启动依赖。
