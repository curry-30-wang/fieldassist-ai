# 客户欠款与常用资料设计

## 范围

本轮只增加两个功能：独立的客户欠款登记，以及客户、供应商、车辆和司机的常用资料选择。生产记录、材料库存、成本利润、设备管理等功能不在本轮范围内。

## 客户欠款

欠款不自动关联生产记录或历史档案，由老板手动维护一张简单清单。每个客户一条当前记录，包含：客户名称、应收金额、已收金额、剩余欠款、约定收款日期、收款状态和备注。剩余欠款由应收金额减已收金额自动计算；状态根据剩余金额和已收金额显示为“未收”“部分收款”或“已结清”。支持新增、修改、删除、按客户查询，并可导出当前客户的简单 Excel 对账单。

## 常用资料

基础资料增加“供应商”“车辆”“司机”三个类别，并保留现有“客户”类别。生成或导出可编辑 Excel 时，客户、供应商、车牌号和司机字段使用下拉选择；下拉列表来自基础资料。仍允许直接输入新名称，保存后可在基础资料中维护。资料支持新增、修改、删除。

## 数据与操作

- 常用资料继续存放在本机 SQLite 数据库中，避免增加新的文件格式。
- 欠款单独使用 SQLite 表保存，删除前要求当前用户确认，误删可通过备份恢复。
- 所有金额使用两位小数显示，剩余欠款不允许显示负数；多收款时按 0 显示并在备注中保留说明。
- 页面保持单机、单用户、简洁操作，不增加联网、多用户和自动生产关联。
